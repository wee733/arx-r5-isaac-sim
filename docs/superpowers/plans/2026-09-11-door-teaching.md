# ARX 门任务交互示教与试采计划

**目标：** 尝试录制 3 条物理执行的旋钮解锁、拉缝、换抓侧沿、拉门示范，供用户检查。
**架构：** Isaac Sim 常驻进程接收逐段动作，返回状态与腕部/总览图片；复用 cuMotion
进行自由空间规划，接触动作使用连续 IK。录制实际状态和指令，成功与失败分别保存。
**技术栈：** Isaac Sim 5.1、ROS 2 Jazzy/cuMotion、Pinocchio、NumPy、FFmpeg、LeRobot v2。
**任务约束：** 见 `docs/door_data_generation.md`。无需 RL，不直接驱动门、不伪造成功。

- [ ] 检查 cuMotion 运行环境和机器人运动学、建立受限的交互控制入口。
- [ ] 用静态变换/IK 检查确认夹爪坐标，渲染单腕部画面。
- [ ] 逐段尝试固定场景，保存截图、控制命令与物理反馈；以反馈调整抓握。
- [ ] 若全流程成功，重复少量示范并导出 LeRobot 数据；失败则保留尝试录像与原因，
      不创建假成功训练集。
- [ ] 检查录像帧数、动作/状态同步及生成文件，向用户交付样本与实际限制。

接口：`observe` 返回关节、门状态和图像；`joints`/`pose`/`trajectory` 执行有限时长动作；
`begin`/`end` 管理录制；`shutdown` 只关闭本任务的仿真进程。
核心验证：关节目标不越限；IK 与实际 USD 位姿一致；记录当前观测与下一步指令；
成功条件必须包含解锁、换抓和开门，而不是只看最终门角。
